# SQL Learning

Repository containing exercises, notes, examples, and practice developed while learning and reviewing **SQL**.

The main purpose of this repository is to consolidate SQL fundamentals through practical exercises and experimentation.

## 📚 Contents

The repository is organized into different sections covering SQL concepts and database fundamentals:

* **Database** — Database-related concepts and practice.
* **Reading** — Queries and exercises focused on retrieving and reading data.
* **Table** — Practice related to table creation and manipulation.
* **Writing** — Exercises focused on inserting and modifying data.

## 🎯 Learning Objectives

The main objectives of this repository are:

* Strengthen SQL fundamentals.
* Practice writing and understanding SQL queries.
* Understand relational databases and their structure.
* Work with tables and relationships.
* Practice data retrieval and manipulation.
* Build a solid foundation for working with PostgreSQL and data engineering.

## 🛠️ Technologies

* SQL
* Relational databases

Additional database technologies may be added as the learning path progresses.

## 📌 Repository Status

This is an **active learning repository**. Its content will evolve as new SQL concepts, exercises, and projects are studied and practiced.

The exercises and examples are intended primarily for educational purposes.
